# Anime Tracker API (Shikimori Clone)

Асинхронный REST API сервис для каталога аниме, ведения личного списка просмотра и написания рецензий с рейтингом.

## Стек технологий
* **Backend:** FastAPI, Python 3.12+
* **База данных:** PostgreSQL, SQLAlchemy 2.0 (async), Alembic
* **Кэширование:** Redis (`redis.asyncio`)
* **Безопасность:** JWT-аутентификация, хеширование паролей (`pwdlib`), ролевая модель (`admin` / `user`)
* **Инфраструктура:** Docker, Docker Compose

## Основной функционал
* **Каталог аниме и жанров (`/animes`, `/genres`):** CRUD-операции для администраторов, связь многие-ко-многим, мягкое удаление (`is_active`), автоматический расчёт среднего рейтинга в карточке тайтла.
* **Авторизация (`/users`):** регистрация, выдача Bearer JWT-токена (`POST /users/token`), разделение прав доступа.
* **Личный список просмотра (`/watchlist`):** добавление аниме по названию, смена статуса (`watching` / `watched`), фильтрация и мягкое удаление.
* **Отзывы (`/reviews`):** оценка от 1 до 10 и текст рецензии (ограничение: 1 отзыв от пользователя на тайтл), инвалидация кэша Redis при изменении оценок.

## Запуск проекта через Docker

1. Клонируйте репозиторий и создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
2. Запустите контейнеры:
   ```bash
   docker compose up -d --build
   ```
3. Примените миграции базы данных:
   ```bash
   docker compose exec web alembic upgrade head
   ```
4. Откройте интерактивную документацию Swagger UI: `http://127.0.0`
